# Weekly Review Ritual

> COS protocol for end-of-week review and next-week planning. Best done Sunday evening or Monday morning. Invoked by Principal saying "weekly review" or "week retro".

---

## Protocol Steps

### 1. Review the Past Week

```
ACTION: Read weekly log (full file)
ACTION: {{TASK_MANAGER}} → Get daily highlights/summaries (Monday through Sunday)
```

Summarize:
- Total tasks completed across the week
- Time spent by channel/category (from daily highlights if available)
- Patterns: recurring deferrals, overcommitment days, productive days

### 2. Assess Weekly Objectives

```
ACTION: {{TASK_MANAGER}} → Get this week's objectives
```

For each objective:
- Met / Partially met / Not met
- What contributed or blocked progress

### 3. Review Project Progress

```
ACTION: Scan 03_Curated/Sovereign/Spaces/ for project notes with open tasks
ACTION: Check quarterly focus document
```

- Are projects advancing toward quarterly outcomes?
- Any project stalled for >1 week?
- Any new efforts that need a channel or Space created?

### 4. Backlog Triage

```
ACTION: {{TASK_MANAGER}} → Get all backlog tasks
```

- Review near-term items — still valid? Pull any for next week?
- Review "someday" items — any that should be promoted or deleted?
- Check for stale items (sitting in backlog >4 weeks without movement)

### 5. Set Next Week's Objectives

Ask Principal for 2-4 objectives for next week. Create them:
```
ACTION: {{TASK_MANAGER}} → Create weekly objective (title, week start date)
```

Objectives should be:
- Specific and completable within a week
- Aligned to quarterly focus
- Ideally tied to a channel/project

### 6. Plan Monday

```
ACTION: {{TASK_MANAGER}} → Get next Monday's tasks
ACTION: {{TASK_MANAGER}} → Get next Monday's calendar events
```

- Pre-load Monday with 3-5 high-priority tasks from backlog
- Ensure at least one task per active objective

### 7. Write Weekly Retro Section

```
ACTION: Append "## Weekly Retro" section to weekly log
```

Format:
```markdown
## Weekly Retro

### Metrics
- Tasks completed: {X}
- Tasks deferred: {Y}
- Objectives: {met}/{total}
- Overcommitted days: {count}/5

### Wins
- {Principal-reported wins}

### Patterns & Observations
- {COS analysis: recurring themes, blockers, time allocation insights}

### Adjustments for Next Week
- {Changes to approach, channel focus, time allocation}

### Next Week Objectives
1. {objective 1} — Channel: {channel}
2. {objective 2} — Channel: {channel}
3. {objective 3} — Channel: {channel}
```

### 8. Update Quarterly Focus (If Needed)

If priorities have shifted, update the quarterly focus document:
- Add new milestones
- Adjust time allocation targets
- Record strategic decisions

### 9. Create Next Week's Log File

```
ACTION: Create next week's log file with frontmatter template
```

---

## Trigger Phrases

- "Weekly review"
- "Week retro"
- "Let's review the week"
- "COS, weekly check-in"
- "Plan next week"

---

## Timing

- Ideal: Sunday 7-8 PM or Monday morning before daily planning
- Duration: 15-30 minutes with Principal
- Can be split: Retro on Sunday, Planning on Monday morning

---

## Outputs

1. Weekly retro section in current week's log
2. 2-4 weekly objectives created in task manager
3. Monday pre-loaded with priority tasks
4. Quarterly Focus updated (if warranted)
5. Next week's log file created (empty template)
